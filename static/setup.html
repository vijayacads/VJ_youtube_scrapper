🔑 YouTube API Key Setup

Welcome to VJ Youtube Amaze! Let's get you started in just 5 minutes.

⚠️ Important: Why You Need Your Own API Key
Each person must create their own API key using their personal Google account. This is completely FREE and only takes a few minutes. Don't worry - we'll guide you through every step!
✅ It's FREE!
Google gives you 10,000 free requests per day - that's enough for thousands of videos!

Follow These Simple Steps:

Step 1: Open Google Cloud Console
Click this link to open Google Cloud Console in a new window:
👉 Open Google Cloud Console

Sign in with your Google account (the same one you use for Gmail or YouTube).
Step 2: Create a New Project
At the top of the page, you'll see "Select a project" - click on it.

Then click the "New Project" button.

Enter any name you like (e.g., "My YouTube Scraper" or "VJ Youtube Amaze").

Click "Create" and wait a few seconds for it to finish.
Step 3: Enable YouTube Data API
Once your project is created, click on the ☰ (hamburger menu) at the top left.

Go to "APIs & Services" → "Library"

In the search box at the top, type: YouTube Data API v3

Click on "YouTube Data API v3" from the results.

Click the big "ENABLE" button and wait for it to finish.
Step 4: Create Your API Key
Click on "APIs & Services" → "Credentials" (from the left menu).

Click the "+ CREATE CREDENTIALS" button at the top.

Select "API Key" from the dropdown menu.

A popup will appear showing your API key! It will look something like: AIzaSyC1234567890abcdefghijklmnopqrstuvw

Copy this entire key - you'll paste it below.
Step 5: Paste Your API Key Here
Paste the API key you just copied into the box below, then click "Save API Key".

Don't worry - your API key stays on your computer and is completely private.
Need Help?
• Make sure you're signed in to your Google account
• The API key should start with "AIza"
• Each person needs their own unique API key
• If you get stuck, try the steps again - they only take 2 minutes!
